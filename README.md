## 💡 Como os Desafios Funcionam na DIO

Nos desafios de JavaScript da DIO, a entrada e saída de dados utilizam duas funções globais nativas da plataforma:

- `gets()`: lê uma linha de entrada de dados fornecida pelos casos de teste.
- `print()`: imprime o resultado esperado e pula para a próxima linha automaticamente.
